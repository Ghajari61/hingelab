# Library shapes

Every shape in the Parametric library is generated by code in `lib/parametric/source/library.ts`; no third-party models are bundled.

| Id | Shape | Source | Licence |
|---|---|---|---|
| abstract-head-cc0 | Stylised face relief, about 160 x 220 mm | Procedurally generated by HingeLab | CC0 1.0 |
| sphere | Icosphere, radius 100 mm | Procedurally generated | CC0 1.0 |
| torus | Torus around the wall normal | Procedurally generated | CC0 1.0 |
| wave-panel | Sine relief, 200 x 150 mm | Procedurally generated | CC0 1.0 |
| ripple | Fading rings, 220 x 220 mm | Procedurally generated | CC0 1.0 |
| vase | Turned profile around Y | Procedurally generated | CC0 1.0 |
