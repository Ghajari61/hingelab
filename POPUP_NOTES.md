## Decisions and bounded implementations
- Followed Clock's GeneratorDef/schema/build/check architecture. Reused Clipper booleans/offsets, shared kerf compensation and sheet arrangement, HarfBuzz engraving, existing SVG/DXF/PDF/LightBurn exports and Pro download checks.
- The requested list actually contains 27 named designs; all 27 are included. Calibration already exists as a utility, so catalog totals are computed instead of forcing an inaccurate literal 15.
- All designs can be previewed; downloads require Pro through existing gating. Batch personalization uses the shared batch path and existing plan limits.
- Finished gap is the nominal resulting opening, including kerf allowance. Tilt depth therefore uses this finished gap directly; adding kerf again would double-count it. Bevel cutting requires capable equipment.
- Two supports use crossed half-lap ribs. Three/four use radial half-ribs and a slotted central hub to avoid coincident interlocking solids. Tests confirm connected individual rib pieces; this is not a load certification.
- Long part labels caused an existing placement test to exceed 20 seconds. Blank/Rib labels avoid that costly fit search; no timeout was increased.
- Nested sets are circular open-centre annular blanks, 2–5 sizes where dimensions permit. They occupy each other's centre waste, rather than merely packing rectangular bounds. Non-circular nested sets and too-small rings return explicit errors. Open centres change the product: these are not closed-bottom bowls.
- Spiral cuts use an inscribed circular Archimedean construction. Their open preview samples ring heights; it is not a continuous elastic-strip simulation. Shape-following offsets apply to concentric rings.
- The preview is a target assembly, not proof that plywood, MDF or acrylic can flex to that shape. Relief lengths are bounded to avoid adjacent slot collisions. Physical coupons and assembly prototypes are still necessary. Centre-post designs may require radial supports/external fixtures; accessory feet and plant seats are not rated structural attachments.
- Custom SVG accepts one closed path with no transforms or external assets; SVG script/image/use/foreignObject are rejected. Complex multi-path drawings must be flattened to a single outline first.
- Engraving uses real glyph outlines, including Persian/Arabic. Assembly card is an optional additional sheet part, preserving the common export pipeline.
- Installer packages the existing working tree, including pre-existing local UI changes; those unrelated source changes are deliberately not committed as Pop-up work.
